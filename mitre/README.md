# mitre — local MITRE ATT&CK dataset (versioned)

A versioned, locally-stored copy of MITRE ATT&CK tactics/techniques so the platform works fully **offline** and coverage views are reproducible.

Key rule: mappings are analytical judgements supported by documented evidence in each rule. The UI will show technique descriptions and *why* a detection maps to it, and will not present mappings as authoritative.

See `../docs/mitre-attack.md`.
